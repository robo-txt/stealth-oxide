# Security policy

## Supported versions

Security fixes are applied to the latest released version. Before the first
public release, fixes are applied to the default branch.

## Reporting a vulnerability

Do not include credentials, cookies, proxy URLs containing secrets, or an
exploitable proof of concept in a public issue. Use GitHub's private security
advisory reporting for this repository. Include the affected version, impact,
reproduction conditions, and the smallest safe demonstration available.

Maintainers should acknowledge a report within seven days. Resolution timing
depends on severity and whether a Chromium or Chromiumoxide change is required.

Classification decisions made by third-party bot or fraud systems are not
security guarantees of this crate. Only test systems and network routes you are
authorized to use.
